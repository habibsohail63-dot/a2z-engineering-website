# A2Z Signature Luxury - consolidated review

This package uses the Signature Enhanced design as its baseline, preserving its original luxury layout and the original working cost estimator rather than replacing it with the later scope-only planner.

## Preserved and consolidated
- Original homepage composition, including the A2Z commitment interlude.
- Existing About, Services, service detail, Projects, project detail, and Contact routes.
- Original PKR indicative cost estimator with four construction types, Marla/Square Feet, and Economy/Standard/Premium allowances.
- WhatsApp estimate handoff and contact inquiry flow.
- Original brand palette, responsive styling, and reduced-motion handling.
- Lightweight interactive architectural wireframe canvas integrated into the hero as a visual enhancement.

## Important business-content notes
- Cost estimator rates are illustrative placeholders from the existing project source, not approved A2Z quotations. Confirm rates before public launch.
- Portfolio/hero images are concept visuals and must remain labeled as such unless replaced with verified company project photographs.
- The temporary typographic A2Z mark is not a substitute for the official company logo.
- The contact form hands the inquiry to WhatsApp; it does not store submissions in a database.

## Local verification
Run `npm install`, `npm run build`, and `npm run dev` from this folder. A full production build could not be executed in the preparation environment because package registry access timed out and the required Vite/Vitest dependencies were not installed here.
